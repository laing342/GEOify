## 二、思路与结论

### 核心思路

基于 Geoify 开源项目进行魔改，新增 4 个 TypeScript 源文件，将 Geoify 扩展为"静态站生成器 + llms.txt + JSON-LD Schema + 一键部署"的 GEO 优化工具。不修改任何原有代码，只做扩展。

### 关键技术决策

1. **纯静态 HTML** — 所有内容在网页源代码中可见，AI 爬虫能直接读取，不依赖 JS 动态渲染
2. **FAQPage JSON-LD** — 遵循 schema.org 规范，标记文字与页面可见文字完全一致
3. **robots.txt + sitemap.xml** — 放行百度、神马、字节跳动、Bing 及 AI 检索爬虫（GPTBot/PerplexityBot/anthropic-ai 等）
4. **llms.txt** — 符合 llmstxt.org 标准，为 AI 引擎提供站点导航
5. **答案先行 + 事实密度 + 结构化** — 每篇内容开篇 40–80 字直接给结论，FAQ 用 Q&A 格式，城市页用价格对比表
6. **合规** — 所有示例数据标注 [示例]/[假设]/[待核实]，无绝对化用语，五条红线明确声明

### 主要结论

1. 轻遇星当前 AI 可见度为 0 — 40 题 × 6 引擎，301 次查询，品牌提及 0 次。基线确立
2. 原因明确 — 站点上线 < 24 小时，搜索引擎尚未索引，微信生态内无公开页面
3. Week 2 复测预期 — 搜索引擎收录后，被引用率应开始从 0 上升
4. GEO 可行性 — 通过持续内容优化 + 结构化数据 + 迭代跟踪，AI 引用可建立
