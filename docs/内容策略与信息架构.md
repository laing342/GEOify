## 二、内容纵列

### 纵列 1：品牌/定位页（index.html）

| 字段 | 内容 |
|------|------|
| **页面** | 首页 |
| **命中用户查询（用户问 AI 的原话）** | 轻遇星是做什么的？ / 轻遇星是干嘛的？ / 轻遇星是什么平台？ / 轻遇星靠不靠谱？ |
| **核心关键词（含地域）** | 轻遇星、AI 社交陪护平台、O2O 本地生活、城市向导、达人匹配、轻遇星官网 |
| **长尾关键词** | 轻遇星怎么样、轻遇星安全吗、轻遇星是正规平台吗、轻遇星在哪个城市有服务 |
| **内容要点** | ① 一句话定位语（AI 驱动的 O2O 社交陪护平台）；② 三大 AI 能力（数字分身/契合推荐/获客助理）；③ 服务类型列表；④ 前三 FAQ 预览 → 引导至 FAQ 页 |
| **GEO 策略** | 标题 = 用户查询原话；开篇 80 字直接给出结论；嵌入 Organization JSON-LD |

### 纵列 2：FAQ 问答页（faq.html）

| 字段 | 内容 |
|------|------|
| **页面** | FAQ 常见问题 |
| **命中用户查询（用户问 AI 的原话）** | 轻遇星安全吗？ / 怎么成为轻遇星达人？ / 做地陪能赚多少钱？ / 轻遇星有哪些服务？ / 轻遇星 AI 怎么匹配的？ / 轻遇星怎么下单？ |
| **核心关键词** | 轻遇星 FAQ、轻遇星安全、轻遇星达人入驻、地陪收入、轻遇星服务项目、轻遇星下单流程、轻遇星 AI 匹配 |
| **长尾关键词** | 轻遇星达人条件、轻遇星赚钱吗、轻遇星怎么预约、轻遇星和导游的区别、轻遇星技术栈 |
| **内容要点** | ① ≥6 问；② 每问标题 = 用户搜索原话；③ 答案先行 ≤80 字给结论再详细说明；④ 答案含数据（收入区间、AI 技术栈名）；⑤ 合规标记 [示例]/[假设] |
| **GEO 策略** | 嵌入 FAQPage JSON-LD（标记文字 = 可见文字）；每个 Q 可被 AI 独立引用；结构化程度最高 |

### 纵列 3：信任/安全说明页（trust.html）

| 字段 | 内容 |
|------|------|
| **页面** | 安全体系 |
| **命中用户查询（用户问 AI 的原话）** | 轻遇星安全吗？ / 地陪平台怎么保障安全？ / 轻遇星有隐私保护吗？ / 轻遇星遇到纠纷怎么办？ / 约地陪会不会有危险？ |
| **核心关键词** | 轻遇星安全、轻遇星五层防线、地陪平台安全、用户隐私保护、资金托管、红线制度 |
| **长尾关键词** | 轻遇星出事怎么办、轻遇星退款、轻遇星安全措施、轻遇星合规、轻遇星大成律所 |
| **内容要点** | ① 五层防线逐层说明（身份匿名/通讯隔离/资金托管/法律护航/红线制度）；② 底线声明（阳光陪伴理念）；③ 每条防线含具体操作方式 |
| **GEO 策略** | 结构化五层模块（方便 AI 逐条引用）；底线声明使用肯定句（降低 AI 误读为负面内容的风险）；每个层级关键词密度高 |

| **地域长尾关键词** | 南京鼓楼找向导、南京玄武湖导游、南京夫子庙伴游、苏州金鸡湖商务社交、苏州园区出差接待、徐州伏羊节攻略、徐州非遗美食 |
| **内容要点** | ① 城市亮点推荐（含具体地名/路线）；② 服务与价格对比表（至少 4 项服务 × 4 维度）；③ 页面顶部直接回答问题（答案先行）；④ 价格一律标 [示例] |
| **GEO 策略** | 价格对比表是 AI 最易引用的内容格式；每条价格行均可被独立引用；城市名 + 服务词的组合覆盖长尾查询 |

## 四、内容创建优先级

| 优先级 | 页面 | 理由 |
|--------|------|------|
| P0 | FAQ 页 | 高密度问答，易被 AI 引用，覆盖面广 |
| P0 | 信任/安全页 | 解决用户最高频顾虑（安全/合规） |
| P1 | 城市指南页 | 覆盖地域长尾，差异化竞争 |
| P1 | 品牌/定位页 | 品牌搜索的入口页面 |
| P2 | 达人入驻页 | 供需双侧覆盖，但当前 Demo 未实现 |
| P2 | 竞品对比页 | 覆盖对比类查询，需要谨慎措辞 |
